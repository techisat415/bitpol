# Mainnet API Benchmark

This report is generated by `cmd/benchmark` against an API backed by a
BigQuery-exported newline-delimited wallet corpus. It must not be interpreted
as a production result until the request count, source block range, API
revision, and infrastructure are recorded.

Run:

```bash
go run ./cmd/benchmark \
  -base-url http://localhost:8080 \
  -wallet-file ./wallets.txt \
  -requests 100000 \
  -concurrency 512 \
  -output BENCHMARKS.md
```

The runner alternates lineage and cycle requests and emits P50, P95, P99, and
failure counts.
